Build a complete, professional, fully functional web application called "AgriMatch" 
for a Final Year Project. This is a smart agriculture platform that collects soil 
and crop data from across the country via crowdsourcing and internet sources, then 
uses matching algorithms and deep learning to recommend the most suitable crops for 
specific soil types, detect pests, and maximize farmer income and harvest yield.

============================================================
TECH STACK
============================================================
- Frontend: HTML5, CSS3, Vanilla JavaScript (no frameworks)
- Charts: Chart.js (CDN)
- Icons: Font Awesome 6 (CDN)
- Fonts: Google Fonts — "Poppins" for headings, "Inter" for body text
- Maps: Leaflet.js (CDN) for Pakistan agricultural zone map
- Backend simulation: localStorage for demo data persistence
- No backend required — use hardcoded JSON datasets for demo
